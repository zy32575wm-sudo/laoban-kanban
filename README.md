# 老板看板（laoban-kanban）

一个给豆包电脑版用的技能：把格式很乱的经营表，按「问、洗、算、看、挑」五步做成一张能回答老板问题的看板。

## 怎么装

打开豆包电脑版，切换到「工作」，对豆包说：

```
豆包你好，帮我安装 GitHub 上 zy32575wm-sudo 的 laoban-kanban
```

## 怎么用

新建一个工作任务，输入「/」选「老板看板」，把你的表拖进去，再写上老板问了什么，比如：

```
老板问：为什么 7、8 月利润少了？下个月该怎么做？
```

它会一步一步做，每步做完先给你看，你说「继续」再往下。

## 提醒

- 它会先备份原表再修改，重要的表你自己最好也先复制一份。
- AI 算的数会出错，交给老板之前，挑几个数拿原表核对一下。
